# 命令列表

本文档列出了 Odysseia Forum Search Bot 的所有可用命令。

## 用户命令

### 搜索相关（斜杠命令）

| 命令 | 说明 |
|------|------|
| `/全局搜索` | 开始一次仅自己可见的全局搜索，支持标签、关键词、作者、时间范围等多维度筛选 |
| `/搜索作者 [作者]` | 快速搜索指定作者的所有帖子 |
| `/查看收藏` | 查看和搜索你已收藏的帖子 |

### 搜索相关（右键菜单）

| 菜单项 | 触发方式 | 说明 |
|--------|----------|------|
| `搜索作品` | 右键点击用户头像 → App | 搜索该用户的全部作品 |

### 收藏相关（右键菜单）

| 菜单项 | 触发方式 | 说明 |
|--------|----------|------|
| `⭐ 收藏此帖` | 右键点击帖子消息 → App | 将帖子添加到你的收藏列表 |
| `➖ 移除收藏` | 右键点击帖子消息 → App | 将帖子从你的收藏列表中移除 |

### 偏好设置

搜索偏好设置（作者偏好、显示模式、结果数量、时间范围等）已集成在搜索界面中，可通过搜索面板内的设置按钮打开，无需单独命令。

### 作品更新

| 命令 | 说明 |
|------|------|
| `/发布更新到索引页 [更新消息] [更新说明] [版本]` | 作者在当前作品帖内正式发布一条更新；版本可选 |
| `/更新提醒设置 查看` | 查看当前作品的自动同步和检测提醒设置 |
| `/更新提醒设置 修改 [自动同步] [不再提醒]` | 修改当前作品的检测偏好；两项设置互斥 |
| `/更新提醒设置 重置` | 恢复为提醒开启、自动同步关闭 |

## 管理员命令

> 以下命令需要服务器管理员或 Bot 管理员权限。

### 索引管理

| 命令 | 说明 |
|------|------|
| `/构建索引` | 对当前论坛频道的所有帖子（包括归档帖子）进行索引 |
| `/移除索引` | 移除当前论坛频道的所有帖子索引 |

### 搜索面板

| 命令 | 说明 |
|------|------|
| `/创建公开全局搜索` | 在当前频道创建公开的全局搜索面板，任何人都可使用 |
| `/创建频道搜索` | 在当前帖子内创建频道搜索按钮，用于搜索当前频道内的帖子 |

### 配置管理

| 命令 | 说明 |
|------|------|
| `/配置 全局设置` | 打开 Bot 配置面板，调整搜索排序算法参数 |
| `/配置 互斥标签组` | 配置互斥标签组（同组标签在搜索时互斥） |
| `/配置 重载配置` | 重新加载 `config.json` 配置文件，无需重启 Bot |
| `/配置 刷新缓存` | 手动刷新所有核心缓存（标签、频道、配置） |

### Banner 管理

| 命令 | 说明 |
|------|------|
| `/banner 创建申请通道` | 在当前频道创建 Banner 申请按钮（使用 `config.json` 配置） |
| `/banner 查看状态` | 查看 Banner 系统当前状态（轮播列表、等待列表、各频道配额） |
| `/banner 删除轮播 [thread_id]` | 从轮播或等待列表中删除指定 Banner |

> 详细的 Banner 系统说明请参阅 [Banner 系统文档](banner-system.md)
